# FolderPDF：Windows 图片文件夹批量转 PDF

[English](README.md) · [常见问题 / FAQ](FAQ.md)

FolderPDF 可以把图片文件夹批量转换为 PDF：**每个文件夹生成一份 PDF**，也可以将队列中的图片全部合成一份。适合整理产品照片、设计参考图、拍照票据和扫描图片。

## 每个图片文件夹生成一份 PDF

1. 从 itch.io 页面下载 `FolderPDF-0.1.2-Windows-x64.zip`，完整解压。
2. 打开 `FolderPDF-win32-x64-v0.1.2`，运行 `FolderPDF.exe`。保留同目录所有文件和 `resources` 文件夹，不要单独复制 EXE。无需另装运行时；便携程序未进行数字签名。
3. 添加图片文件夹。子文件夹会分别成为任务，同一文件夹的图片按文件名自然排序，例如 `1、2、10`。
4. 检查缩略图，双击查看大图，拖动调整页面顺序。可批量旋转、移除选中页面，也可撤销最近一次移除。
5. 选择“每个文件夹一份”或“全部合成一份”，设置纸张和保存位置，然后生成 PDF。
6. 完成后查看各 PDF 的实际页数和体积。若图片或任务失败，修复对应源图片后重试失败项；成功的 PDF 会保留，合并文档失败则需整份重试。

勾选页面用于编辑。**导出包含所有队列任务中尚未移除的全部页面**，并非只导出勾选的缩略图。

## 本机处理与输出

- 图片在本机处理，不上传图片，不修改或删除源文件。
- 输出遇到同名 PDF 时自动添加数字后缀，保留已有文件。
- 纸张可选跟随图片、A4 或 Letter。A4 和 Letter 等比排版、保留边距，不裁切图片。
- 可选清晰优先或较小文件预设。较小文件可能损失细节，不保证固定 KB/MB，也不保证每次都比清晰模式更小。重要小字建议选清晰优先并检查成品。
- 软件记住导出设置和仍有效的保存目录，不保存图片整理队列；关闭前请完成导出。

## 格式与限制

支持 JPEG、PNG、WebP、单页 TIFF 和 AVIF，具体以程序解码结果为准。

不支持已有 PDF、HEIC、BMP、SVG、动画或多页图片；不含 OCR、已有 PDF 编辑或通用 PDF 压缩功能。

一次最多 5,000 页、1,000 个输入路径。单张源图片不超过 1 亿像素和 256 MiB；大量高分辨率图片建议分批处理。
